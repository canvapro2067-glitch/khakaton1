# ОАО «Молочный мир» — автоматизация логистики (Гродно)

Веб-система распределения 214 торговых объектов по 16 автомобилям: VRP с грузоподъёмностью, минимумом загрузки 90%, запретом исторического центра для машин тяжелее 1,5 т, окнами доставки и сменой 8 часов.

Карта архитектуры и модулей: [docs/PROJECT_CODEX.md](docs/PROJECT_CODEX.md).

Временный хостинг фронта: [docs/DEPLOY_TIINY.md](docs/DEPLOY_TIINY.md) (tiiny.host + отдельный API).  
Netlify + GitHub: [docs/DEPLOY_NETLIFY.md](docs/DEPLOY_NETLIFY.md).

## Запуск

```powershell
python -m pip install -r requirements.txt
cd frontend
npm install
cd ..
.\start.ps1
```

- Диспетчер: http://localhost:5173  (логин `dispatcher` / `dispatcher`)
- С телефона (та же Wi‑Fi, что и ПК): `http://192.168.0.198:5173/` — точный адрес смотрите в консоли после `npm run dev` (строка **Network**). `localhost` с телефона не работает.
- Водитель 1,5 т: `driver1` / `driver`  (остальные `driver2`…`driver16`)
- API: http://127.0.0.1:8000/docs

При первом старте импортируется `data.xlsx` и сразу считается распределение.

Ключ Яндекс Карт (пробки, грузовой маршрут, геокодер) — в `.env`:

```
YANDEX_MAPS_API_KEY=
YANDEX_ROUTING_API_KEY=
```

Ключ возьмите в [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/) (JavaScript API + HTTP Геокодер; отдельно Routing API). В ограничениях ключа укажите `http://localhost:5173/*` и для телефона в той же сети — `http://192.168.0.198:5173/*` (ваш IP из **Network**). После правки `.env` перезапустите API.

С ключом панель диспетчера показывает Яндекс.Карты и слой пробок. Без ключа — OpenStreetMap. Матрица расстояний без Routing API — городская модель (haversine × 1,38 + коэффициент пробок по часам). Ограничения Советская / Мостовая / Замковая заданы в алгоритме отдельно от «грузового режима» Яндекса.

Google OR-Tools подключается автоматически, если пакет установлен (на Python 3.15 колёс нет — используется встроенный CVRPTW той же постановки).
